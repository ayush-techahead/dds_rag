# ICF/IID Program Plan Template : CA Department of Developmental Services

**Source:** [https://www.dds.ca.gov/services/icf/icf-iid-program-plan-template/](https://www.dds.ca.gov/services/icf/icf-iid-program-plan-template/)

---

A Program Plan template has been created which may be used to assist with the development of either an ICF/DD-H or ICF/DD- N type facility. Within the document, italicized font is instructions, directions, and/or suggestions, while regular font is recommended text to use within your document. Red text indicates information specific to a particular facility type. This template format is optional. It is not required and is intended only to assist in the development process of an ICF/DD-H or ICF/DD-N Program Plan.

[Program Plan Template](<https://www.dds.ca.gov/wp-content/uploads/2019/02/programPlanTemplate-2.docx>)

Please visit the [Program Plan Information and Development](<https://www.dds.ca.gov/services/icf/program-plan-information-and-development/>) Web page for more information.

If you have any questions, please contact the Community Living Section at 916-654-1965, or send an e-mail to [ddscls@dds.ca.gov](<mailto:ddscls@dds.ca.gov>).
