The Department of Developmental Services (Department) is pleased to invite you to join a webinar on Wednesday, January 28, 2026, about proposed updates to the Self-Determination Program (SDP) Orientation. The SDP Orientation provides essential information about the program and is required prior to enrollment. 

In this meeting, the Department will talk about: 

  * The current SDP Orientation
  * Proposed updates to the SDP Orientation
  * How you can provide input on the proposed changes

American Sign Language and Spanish interpretation will be provided. A public comment period will also be included in the agenda.
