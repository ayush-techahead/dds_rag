The Department of Developmental Services (Department) invites you to an informational webinar on April 10, 2025, from 9:00 a.m. to 10:00 a.m. During this webinar, the Department will present information about an initiative to develop a standardized assessment tool to be used across regional centers to determine respite, day care and personal assistance service needs. This project will create a statewide process and build consistency for individuals accessing these services.

## In this informational webinar, we will present:

  * Background of the assessment tool project
  * Purpose of the assessment tool project
  * Highlights of project activities and anticipated dates
