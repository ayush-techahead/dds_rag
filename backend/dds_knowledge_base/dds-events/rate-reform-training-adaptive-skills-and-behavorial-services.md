The Department of Developmental Services invites you to a webinar on November 14, 2024, to provide an overview of the Department’s next directive about Adaptive Skills Training and Behavioral Services.

**Topics will include:**

  * Adaptive Skills Training Licensed Professional and Specialist (service code 605)
  * Behavior Analyst (service code 612)
  * Associate Behavior Analyst (service code 613)
  * Behavior Management Assistant (service code 615)
  * Behavior Technician-Paraprofessional (service code 616)
  * Behavior Management Consultant (service code 620)
  * Client/Parent Support Behavior Intervention Training (service code 048)
