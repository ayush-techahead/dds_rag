# Important Update to the DSP Internship Program : CA Department of Developmental Services

**Source:** [https://www.dds.ca.gov/newsletter/important-update-to-the-dsp-internship-program/](https://www.dds.ca.gov/newsletter/important-update-to-the-dsp-internship-program/)

---

Calling all service providers looking to expand their Direct Service Professional (DSP) workforce!

Providers can now sign up for [the DSP Internship Program directly on the program’s online portal](<https://cadds.gov1.qualtrics.com/jfe/form/SV_5vcuGorm7WrriR0>)!

## What’s New?

When a provider applies through the portal, they will submit:

  * Vendor name and address

  * Vendor number

  * Regional Center associated with the vendor number

  * Primary service code where the DSP Intern will be mentored

  * Sanction status

  * Name of the provider’s point of contact, email, and phone number of a contact person

If approved, the provider’s information will be provided to the program contractor for next steps.

## What is the DSP Internship Program?

The DSP Internship Program offers participating providers a streamlined, standardized way to mentor and train new DSPs, helping build capacity for supporting Californians with intellectual and developmental disabilities. The program is intended to improve recruitment, training, and retention of quality staff.

To learn more about the program visit the [DSP Internship Program](<https://www.dds.ca.gov/initiatives/workforce-initiatives-4/dsp-internship-program/>) webpage and read the [updated directive with details about recent changes](<https://www.dds.ca.gov/wp-content/uploads/2025/09/D-2025-Workforce-001-1.pdf>).

If you have questions about the DSP Internship Program, please email [Workforce@dds.ca.gov](<mailto:Workforce@dds.ca.gov>)
