# New Public Data Dashboard Online! : CA Department of Developmental Services

**Source:** [https://www.dds.ca.gov/newsletter/new-public-data-dashboard-online/](https://www.dds.ca.gov/newsletter/new-public-data-dashboard-online/)

---

We are excited to share a new public data [dashboard](<https://www.dds.ca.gov/transparency/facts-stats/dds-comprehensive-dashboard/>) that provides caseload trends and spending data. The dashboard contains information back to 2011 and is updated monthly. We hope this dashboard is a useful resource.

The dashboard protects private information about individuals. The website also includes links to:

  * A document that gives an overview of [the methodology](<https://www.dds.ca.gov/wp-content/uploads/2024/09/PublicComprehensiveDashboard_MethodologyOverview_20240911.pdf>) used for the dashboard
  * [Frequently Asked Questions (FAQs)](<https://www.dds.ca.gov/wp-content/uploads/2024/09/PublicComprehensiveDashboard_FAQs_20240911.pdf>) about the dashboard

These two documents are being translated into 20 languages. The translations will be posted on the website once they are available.

Please take a moment to explore the data dashboard and email [analytics@dds.ca.gov](<mailto:analytics@dds.ca.gov>) if you have any feedback to share.
